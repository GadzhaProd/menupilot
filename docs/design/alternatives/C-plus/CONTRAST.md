# Контраст C+

WCAG2 relative luminance, sRGB. В каждой теме 24 пары; все 48 проходят. Минимумы по bg/surface/panel; focus и border требуют 3:1, остальной текст 4.5:1.

| Роль | Light минимум | Dark минимум | Порог |
|---|---:|---:|---:|
| Текст и числа | 12.04:1 | 8.71:1 | 4.5:1 |
| Пояснения | 5.83:1 | 6.70:1 | 4.5:1 |
| Акцент, включая selected фон | 5.74:1 | 6.16:1 | 4.5:1 |
| Положительное изменение | 6.13:1 | 6.78:1 | 4.5:1 |
| Отрицательное изменение | 6.08:1 | 6.68:1 | 4.5:1 |
| Фокус | 5.76:1 | 7.10:1 | 3:1 |
| Граница поля | 3.67:1 | 4.08:1 | 3:1 |
| Текст основной кнопки | 11.66:1 | 11.53:1 | 4.5:1 |
